OpenClaw 接入

官方 Skill 一键接入，让 OpenClaw / Clawdbot 等 AI 助手实时查询 A 股行情。

⚡ 什么是 OpenClaw？
OpenClaw（Clawdbot）是领先的 AI 智能体框架，支持通过 Skill 扩展能力。KLineAPI 提供官方 Skill，安装后你的 AI 助手即可直接查询实时行情、历史 K 线、涨停池、北向资金等数据，无需编写任何代码。

一、下载 Skill

官方 Skill 文件（.skill 格式，zip 压缩包）：

⬇ 下载 klineapi.skill

Skill 包含完整的接口调用脚本与文档，安装后 AI 助手会自动识别并使用。

二、安装到 OpenClaw

步骤操作
1找到 OpenClaw 的 skills 目录（通常在 ~/clawd/skills/ 或 ~/.openclaw/skills/）
2解压 klineapi.skill 到该目录，得到 klineapi/ 文件夹
3重启 OpenClaw / Clawdbot，使 Skill 生效
4在 klineapi/SKILL.md 中填入你的 API Key（或设置环境变量 KLINEAPI_KEY）

三、获取 API Key

注册并登录后，在控制台一键生成 API Key。免费套餐每天 100 次调用，专业版每天 10,000 次。

四、使用示例

安装完成后，直接对你的 AI 助手说：

"查一下贵州茅台现在的股价"
"帮我拉取宁德时代最近 30 天的日 K 线"
"今天有哪些股票涨停了？"
"北向资金今天流入多少？"
"上证指数现在多少点？"

AI 助手会自动调用 KLineAPI 接口并返回实时数据。

五、手动调用（curl）

# 实时行情
curl "https://klineapi.com/v1/quote?code=600519&key=YOUR_API_KEY"

# 历史日 K
curl "https://klineapi.com/v1/kline?code=600519&period=day&count=30&key=YOUR_API_KEY"

# 涨停池
curl "https://klineapi.com/v1/limit_up?key=YOUR_API_KEY"

# 北向资金
curl "https://klineapi.com/v1/north?key=YOUR_API_KEY"

六、Skill 支持的接口

能力接口说明
实时行情/v1/quote单只股票实时价、涨跌幅、五档盘口
