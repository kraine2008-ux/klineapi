快速开始

注册后自动生成 kline_ 开头的 API Key，调用时通过 ?key= 参数或 X-API-Key 请求头传递。

curl "https://klineapi.com/v1/quote?code=600519&key=YOUR_API_KEY"
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://klineapi.com/v1/index"

认证方式

方式示例说明
Query 参数?key=YOUR_API_KEY所有 GET 请求均可使用
请求头X-API-Key: YOUR_API_KEY推荐生产环境使用

所有接口均需要有效 API Key，未携带或无效时返回 401。

批量行情 GET /v1/batch

一次请求获取多只股票行情，代码用逗号分隔，最多 50 只。

curl "https://klineapi.com/v1/batch?codes=600519,000001,300750&key=YOUR_API_KEY"
{
  "code": 0,
  "data": [
    {"code": "600519", "data": {"name": "贵州茅台", "price": 1309.22, ...}},
    {"code": "000001", "data": {"name": "平安银行", "price": 11.20, ...}},
    {"code": "300750", "data": {"name": "宁德时代", "price": 265.30, ...}}

全市场涨幅排行 GET /v1/top

沪深 A 股按涨跌幅降序排列。自主研发行情引擎。

参数类型默认说明
limitint50返回条数，1-100
 
curl "https://klineapi.com/v1/top?limit=20&key=YOUR_API_KEY"

大盘指数 GET /v1/index

返回上证指数、深证成指、创业板指、沪深300、科创50 五大指数。

curl "https://klineapi.com/v1/index?key=YOUR_API_KEY"

涨停池 GET /v1/limit_up

按板块规则过滤的涨停股票池：剔除 ST，主板 ≥9.5%、创业板/科创板 ≥19.5%、北交所 ≥29.5%。

curl "https://klineapi.com/v1/limit_up?key=YOUR_API_KEY"

五档盘口 GET /v1/orderbook

返回买卖五档报价，复用行情源数据。

curl "https://klineapi.com/v1/orderbook?code=600519&key=YOUR_API_KEY"
{
  "code": 0,
  "data": {
    "code": "600519",
    "name": "贵州茅台",
    "price": 1309.22,
    "bid": [{"price": 1309.22, "volume": 2}, ...],
    "ask": [{"price": 1309.23, "volume": 1}, ...]
  }
}

集合竞价 GET /v1/auction

返回当前集合竞价状态（9:15-9:25 开盘竞价、14:57-15:00 收盘竞价）及匹配价格。

curl "https://klineapi.com/v1/auction?code=600519&key=YOUR_API_KEY"

K 线历史 GET /v1/kline

股票历史 K 线数据，支持日/周/月/分钟级，最高 30 年历史。本地历史库优先，响应快。

参数类型默认说明
codestring—股票代码（必填）
periodstringday周期：day/week/month/5min/15min/30min/60min/min1/quarter/year
countint100返回条数，最大 800
startstring—起始日期 YYYY-MM-DD（与 count 互斥）
endstring—结束日期 YYYY-MM-DD
 
curl "https://klineapi.com/v1/kline?code=600519&period=day&count=5&key=YOUR_API_KEY"

跌停池 GET /v1/limit_down

按板块规则过滤的跌停股票池（不含 ST 和 N/C 开头次新股）。全市场扫描，缓存 30 秒。

curl "https://klineapi.com/v1/limit_down?key=YOUR_API_KEY"

炸板池 GET /v1/limit_up_break

盘中曾触及涨停价、当前未封住的股票。缓存 30 秒。

curl "https://klineapi.com/v1/limit_up_break?key=YOUR_API_KEY"

连板天梯 GET /v1/lianban

涨停池 + 本地 K 线计算连板数，按连板数降序排列。

参数类型默认说明
min_lbint1最低连板数筛选，默认 1=全部，如 min_lb=3 只看 3 板以上
 
curl "https://klineapi.com/v1/lianban?min_lb=3&key=YOUR_API_KEY"

昨日涨停 GET /v1/limit_up_yesterday

查询历史交易日涨停池数据。每日 15:05 后自动存档，默认返回最近一次存档。

参数类型默认说明
datestring最近存档日期 YYYY-MM-DD
 
curl "https://klineapi.com/v1/limit_up_yesterday?date=2026-08-07&key=YOUR_API_KEY"

板块列表 GET /v1/board_list

行业/概念/风格板块列表，含成分股数量。数据源：腾讯（行业）+ 同花顺（概念）+ 通达信（风格）。

参数类型默认说明
typestring11=行业 2=概念 3=风格，逗号分隔如 type=1,2
 
curl "https://klineapi.com/v1/board_list?type=1&key=YOUR_API_KEY"

板块成分 GET /v1/sector_detail

指定板块的成分股列表（行业板块全量成分，概念板块成分暂缺）。

参数类型默认说明
namestring—板块名称（必填，需 URL 编码中文）
typeint11=行业 2=概念 3=风格
 
curl "https://klineapi.com/v1/sector_detail?name=%E5%8C%BB%E7%96%97%E6%9C%8D%E5%8A%A1&type=1&key=YOUR_API_KEY"

个股板块 GET /v1/stock_sector

查询单只股票所属的行业/概念/风格板块。

参数类型必填说明
codestring是股票代码，如 600519
 
curl "https://klineapi.com/v1/stock_sector?code=600519&key=YOUR_API_KEY"

板块涨停排名 GET /v1/plates_zt

各板块内涨停股数量和最高连板数排名（行业板块成分齐全，概念暂缺成分）。

参数类型默认说明
typesstring11=行业 2=概念 3=风格
 
curl "https://klineapi.com/v1/plates_zt?types=1&key=YOUR_API_KEY"

ETF 实时行情 GET /v1/etf/realtime

ETF 实时行情，沪市基金代码以 5 开头，深市以 1 开头。

参数类型必填说明
codestring是ETF 代码，如 510300（沪深300ETF）
 
curl "https://klineapi.com/v1/etf/realtime?code=510300&key=YOUR_API_KEY"

ETF K 线 GET /v1/etf/kline

ETF 历史 K 线，优先本地库。

参数类型默认说明
codestring—ETF 代码（必填）
periodint9周期：9=日K 5=周K 6=月K
countint100返回条数，最大 800
 
curl "https://klineapi.com/v1/etf/kline?code=510300&period=9&count=5&key=YOUR_API_KEY"

可转债实时行情 GET /v1/bond/realtime

可转债实时行情，价格已除以 100 修正为实际价格。

参数类型必填说明
codestring是转债代码，如 127045（牧原转债）
 
curl "https://klineapi.com/v1/bond/realtime?code=127045&key=YOUR_API_KEY"

可转债历史 K 线，优先本地库。

参数类型默认说明
codestring—转债代码（必填）
periodint9周期：9=日K
countint100返回条数，最大 800
 
curl "https://klineapi.com/v1/bond/kline?code=127045&count=5&key=YOUR_API_KEY"

交易日历 GET /v1/calendar

A 股交易日历，取自本地历史 K 线库。

参数类型默认说明
countint20返回最近交易日数量，最大 120
 
curl "https://klineapi.com/v1/calendar?count=10&key=YOUR_API_KEY"

代码搜索 GET /v1/search

按股票名称或代码搜索，返回匹配的 A 股标的。

参数类型必填说明
qstring是搜索关键词，如"茅台"或"600519"
 
curl "https://klineapi.com/v1/search?q=%E8%8C%85%E5%8F%B0&key=YOUR_API_KEY"

财务数据 GET /v1/finance

个股财务数据（市值、PE、PB、ROE 等），首次请求拉取缓存 6 小时。

curl "https://klineapi.com/v1/finance?code=600519&key=YOUR_API_KEY"

北向资金 GET /v1/north

北向资金（沪股通+深股通）当日及历史流入流出数据。

curl "https://klineapi.com/v1/north?key=YOUR_API_KEY"

龙虎榜 GET /v1/lhb

龙虎榜数据，支持指定日期查询。

参数类型默认说明

大盘指数别名 GET /v1/market

/v1/market 与 /v1/index 返回相同数据。

全市场排行别名 GET /v1/board

服务状态 GET /v1/status

返回服务运行状态、在线时长、用户数、今日调用量等。

curl "https://klineapi.com/v1/status?key=YOUR_API_KEY"

限流说明

限流基于内存计数器，按「每日 + 每分钟」双维度统计。接口开放数量：免费版 10 个基础接口，专业版/企业版 全部 29 个接口。

套餐每日限额每分钟限额可用接口
免费版100 次10 次10 个基础接口
专业版10,000 次100 次全部 29 个接口
企业版100,000 次不限全部 29 个接口

超过限额返回 429，并附带具体限制说明；免费版调用未开放接口返回 403。服务器时间为 Asia/Shanghai 时区。
